# 预测模型迭代规则

## 目标

盘后回溯用于发现可重复改进的误差，不把偶然命中、赛中随机事件或同一批样本内拟合当成模型提升证据。

## 固定评估链路

1. 每场只使用规定决策时点之前、距离该时点最近的一版不可变赛前快照。
2. 用官方比赛 ID 关联赛果；没有官方 ID、可靠开赛时间或完整概率的记录只进入数据质量统计。
3. 同一比赛的多次快照不能重复扩充训练或测试样本。
4. 正式模型、挑战模型和决策时市场去水概率必须在同一批比赛上比较。
5. 历史样本用于训练与校准，随后发生的比赛用于未来测试；测试结果不得反向参与其自身参数选择。

## 核心指标

- 胜平负、让球胜平负和半全场：Brier、Log Loss、概率分桶校准和首选命中率。
- 比分：完整比分分布 Log Loss、首选命中率和前三覆盖率。
- 总进球：有序概率评分、首选命中率和前二覆盖率。
- 数据健康：官方 ID、开赛时间、决策时赔率、赛果、完整预测字段和可验证赛前情报覆盖率。

## 误差分类

- 数据错误或缺失：先修数据，不用于调参。
- 第二顺位命中：分布覆盖但排序错误，适合做概率校准。
- 强方向反转：最高概率超过 50% 且赛果完全反向，检查过度自信与情报缺口。
- 比分分布偏窄：实际比分或总进球在主要候选之外，检查均值、方差和尾部质量。
- 赛前情报缺口：缺少带时间戳的首发、伤停、轮换或盘口变化证据。
- 待核验赛中事件：只有取得红牌、点球、伤退和 xG 时间线后才能认定为事件驱动。
- 低概率爆冷：单列观察，不让少量极端结果主导模型参数。

## 挑战模型晋级门槛

挑战模型保持影子运行，全部满足后才进入人工审核：

- 未参与调参的未来独立样本不少于 100 场；
- 至少 4 个滚动时间折，其中至少 3 折领先正式模型和市场基线；
- Brier 至少改善 0.005；
- Log Loss 不劣于基线；
- 概率校准误差改善；
- 关键数据完整度不低于 95%。

正式模型最近 50 场 Brier 比市场基线恶化超过 0.01 时触发回滚警报。任何自动晋级均处于关闭状态，只有门槛全部通过并完成人工审核后才能切换正式版本。

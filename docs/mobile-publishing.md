# 手机访问与发布指南

## 已发布网站（推荐）

正式站点使用 HTTPS，手机浏览器直接打开即可。当前站点保持为私有访问，手机需要登录同一个 ChatGPT/OpenAI 账号。常用页面可通过浏览器菜单“添加到主屏幕”，以接近独立 App 的方式打开。

## 同一 Wi-Fi 下本地预览

在项目目录执行：

```powershell
npm run dev:mobile
npm run mobile:url
```

第二条命令会打印局域网地址。确保手机和电脑连接同一 Wi-Fi，并允许 Windows 防火墙访问 Node.js，然后在手机浏览器打开打印出的地址。

桌面端可访问 `http://localhost:3000/mobile-preview`，在一个固定手机画框中切换检查“今日比赛、AI预测、盘口预测、今日推荐、盘后回溯”。

## 微信内个人使用

最省事的方式是在微信“文件传输助手”中发送正式站点链接，再从微信内置浏览器打开并收藏。由于站点是私有的，首次需要完成账号登录。

## 微信小程序接入路径

现有网站可以作为 H5 页面嵌入小程序的 `web-view`。正式上线前仍需要你在微信公众平台完成账号主体、AppID、业务域名和审核发布等账号侧操作：

1. 准备可配置业务域名的微信小程序账号与 AppID。
2. 为网站绑定你可控制的 HTTPS 自定义域名，并把微信提供的校验文件放在域名根目录。
3. 在微信公众平台“开发管理 → 开发设置 → 业务域名”中添加该域名。
4. 新建一个只包含 `web-view` 的小程序壳，入口指向网站 `/matches`。
5. 使用微信开发者工具真机预览，再上传版本、提交审核并发布。

仅做开发调试时，微信开发者工具可以临时关闭合法域名校验；正式发布必须按平台规则配置业务域名。当前 `chatgpt.site` 托管域名不是你可自行放置微信校验文件的自定义域名，因此正式小程序建议先绑定你自己的域名。AppID 和业务域名准备好后，项目可以继续生成小程序壳工程。
